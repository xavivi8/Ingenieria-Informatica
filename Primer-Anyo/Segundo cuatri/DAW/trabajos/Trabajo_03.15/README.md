## Descripción breve

En este trabajo se analiza el uso de **Axios** como alternativa a la **API Fetch** para realizar peticiones HTTP en aplicaciones web.  
Se comparan sus **características técnicas**, **ventajas**, **desventajas** y **casos de uso**, con ejemplos de código y el apoyo de herramientas de inteligencia artificial generativa (IAG).
