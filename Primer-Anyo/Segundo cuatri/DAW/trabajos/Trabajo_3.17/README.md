## Descripción breve

Este proyecto tiene como objetivo explorar los fundamentos de los CMS Headless utilizando Strapi, un CMS
de código abierto que facilita la creación, gestión y distribución de contenido a través de APIs. El proyecto demuestra cómo integrar Strapi
con una aplicación Java basada en Jakarta EE y JSF para gestionar reseñas de usuarios en una tienda online.

## Materiales complementarios

En el ejemplo implementado, hemos desarrollado una aplicación que integra Strapi como CMS headless para gestionar 
y mostrar reseñas de productos en una tienda online. La aplicación se conecta a Strapi
a través de peticiones REST para obtener los datos de las reseñas en formato JSON, los cuales son procesados y 
presentados en la interfaz web. Los usuarios pueden ver las reseñas disponibles y, si tienen privilegios de 
administrador, pueden crear y gestionar reseñas directamente desde el panel de administración de Strapi.
