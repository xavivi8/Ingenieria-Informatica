### **Descripción**

Este trabajo presenta **SvelteJS**, un framework de JavaScript moderno que se diferencia por su enfoque de compilación. A lo largo de la presentación se detallan sus características principales, ventajas frente a otros frameworks como React y Vue, casos de uso, y ejemplos prácticos. También se explora su comunidad, recursos disponibles, y su potencial para el desarrollo de aplicaciones web de alto rendimiento.

### **Materiales complementarios**

**Estructura y descripción de los ejemplos incluidos**:

* `ejemplos/reactividad/`: Demostración de la reactividad automática de Svelte.

* `ejemplos/condicionales/`: Comparativa del uso de condicionales frente a otros frameworks.

* `ejemplos/estilos/`: Ejemplo de estilos con ámbito sin necesidad de módulos CSS externos.

**Instrucciones de ejecución**:

1. Instalar Node.js y npm.

2. Ejecutar `npm install` dentro de cada carpeta de ejemplo.

3. Lanzar con `npm run dev` y abrir `http://XXXXXX:5173` en el navegador.
