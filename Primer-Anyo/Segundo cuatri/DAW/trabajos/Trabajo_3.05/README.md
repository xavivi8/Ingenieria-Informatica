## Descripción breve

Este trabajo tiene como objetivo introducir el uso de la biblioteca de componentes web Shoelace para el desarrollo
de interfaces modernas y accesibles. A lo largo del proyecto, se han realizado una serie de programas en la que
se integran distintos componentes de Shoelace, como botones, diálogos y menús, con el fin de mejorar la experiencia
de usuario sin depender de frameworks pesados. Se explora además la personalización de estilos y la interacción entre
los componentes y el DOM mediante JavaScript.

## Materiales complementarios

El material complementario suministrado es una versión reducida de nuestro
proyecto de prácticas añadido distintas funcionalidades de Shoelace. Es una aplicación donde puedes registrarte
como usuario e iniciar sesión. Si quieres registrarte te saldrá una ventana modal con el formulario para registrarse
y si el formulario es correcto se te creara la cuenta y te saldrá un mensaje diciendotelo. Además, tendriamos una
lista con todos los usuarios que tenemos en el sistema donde tambien tendria un avatar. Se han proporcionado las
vistas donde se configura todo lo relacionado con Shoelace.

Las carpetas del proyecto contienen:

- **Ejemplo1**: Contiene una vista html que muestra las diferencias entre el estilo light y el estilo dark de Shoelace.

- **Ejemplo2**: Contiene una vista html que muestra el código de un botón básico de Shoelace.

- **Ejemplo3**: Contiene una vista xhtml de nuestro proyecto que muestra un formulario de registro con las implementaciones de Shoelace.

- **Ejemplo4**: Contiene una vista html que muestra el uso de avatares de Shoelace.

- **Ejemplo5**: Contiene una vista xhtml de nuestro proyecto que muestra un listado de los usuarios y administradores del sistema con las implementaciones de Shoelace.
