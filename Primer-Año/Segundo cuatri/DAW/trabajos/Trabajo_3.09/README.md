## Descripción breve

Este proyecto tiene como objetivo estudiar el concepto y las ventajas de las Aplicaciones Web Progresivas (PWA). Se presentan las características principales, arquitectura básica, ejemplos funcionales y un análisis de cómo transformar una aplicación web tradicional en una PWA mediante el uso de Service Workers, Web App Manifest y almacenamiento local.

## Materiales complementarios

La carpeta del proyecto contiene dos ejemplos prácticos:

**Ejemplo1**: PWA "Hello World"

Una app básica que muestra cómo registrar un Service Worker y activar el modo offline.

Incluye los archivos esenciales: index.html, service-worker.js, manifest.json, e iconos.

**Ejemplo2**: Lista de tareas PWA

Aplicación más completa con funcionalidad de añadir/eliminar tareas y almacenamiento local.

Funciona completamente offline gracias al uso de caché y localStorage.

**Ejemplo3**: Calculadora de Propinas PWA

Una aplicación web progresiva que permite calcular la propina y el total a pagar introduciendo el importe y el porcentaje deseado. Se trata de una app simple que demuestra cómo una funcionalidad básica puede convertirse en una PWA funcional: instalable y accesible offline
