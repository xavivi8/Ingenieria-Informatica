## Descripción breve
Bulma es un framework CSS ligero, moderno y responsive que simplifica la creación de interfaces web atractivas usando clases predefinidas. En este trabajo hemos utilizado este framework aplicándolo al proyecto de prácticas, estilizando componentes como formularios, botones y cuadrículas, logrando un diseño limpio sin necesidad de Javascript. En nuestro proyecto de prácticas, inicialmente trabajamos con Bootstrap, el cual ha sido sustituído por Bulma.
