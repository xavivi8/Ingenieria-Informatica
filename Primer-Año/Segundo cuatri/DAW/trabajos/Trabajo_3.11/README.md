## Descripción breve

Este proyecto muestra cómo integrar de forma sencilla y práctica PrimeVue para construir una interfaz moderna y accesible. Incluye un diseño modular con un encabezado y barra de navegación, un formulario de registro centrado con validación básica y notificaciones, y un conjunto de tarjetas de películas que aprovechan la carga diferida de imágenes para optimizar el rendimiento. El resultado es una plantilla minimalista y didáctica que cualquier desarrollador o estudiante puede replicar y adaptar para acelerar la creación de interfaces profesionales gracias PrimeVue.

## Materiales complementarios

- ### Proyecto Ejemplo:
Este proyecto es una plantilla base de aplicación PrimeVue para ofrecer una interfaz moderna y accesible. Incluye un encabezado con logo y barra de navegación, un formulario de registro centrado con validación básica, y una sección de tarjetas de películas destacadas que cargan sus pósteres de forma diferida y con tamaño optimizado. De este modo se ha realizado una prueba de una vista html mediante la aplicación de los componentes de PrimeVue.

#### Incluye:

- Encabezado con logo 
- Barra de navegación
- Formulario de registro con validación
- Tarjetas de películas


#### Requerimientos

- Tener instalado Node.js
- Crear un proyecto Vite + Vue
- Instalar las dependencias necesarias para los componentes usados
