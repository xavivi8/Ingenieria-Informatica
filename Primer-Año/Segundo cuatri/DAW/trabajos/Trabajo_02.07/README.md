## Descripción breve

Este proyecto es una aplicación web desarrollada en Java utilizando el framework Vaadin Flow e integrada con Spring Boot. Su objetivo es demostrar el desarrollo integral de interfaces de usuario modernas y reactivas sin necesidad de escribir HTML, CSS o JavaScript directamente. La aplicación incluye ejemplos funcionales como formularios, navegación entre vistas, acceso a base de datos con JPA.
