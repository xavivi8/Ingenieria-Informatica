## Descripción breve
Este proyecto explora AlpineJS como herramienta para dotar de interactividad a páginas HTML de forma simple y ligera.
Se analizan sus ventajas frente a JavaScript puro y otros frameworks más pesados, así como sus principales limitaciones,
buenas prácticas de uso y ejemplos de aplicación en formularios, menús, modales y tabs.

## Materiales complementarios
La carpeta del proyecto incluye varios ejemplos prácticos organizados en subcarpetas:
- **Ejemplo1 - Usos tipicos de AlpineJS:**
Muestra cómo usar `x-data`, `x-model` y `x-show` para mostrar/ocultar campos y validar formularios en tiempo real, menú
desplegable tipo hamburguesa, tabs, modal, tooltip y acordeón.
- **Ejemplo2 - Manejo de datos con AlpineJS:**
Implementación de AlpineJS en nuestra aplicación web cogiendo los datos de la API.

### Otros comentarios
AlpineJS es ideal para desarrollos rápidos que requieren interactividad básica sin la necesidad de adoptar frameworks más
pesados como React o Vue. Recomendado para estudiantes o desarrolladores que trabajan con HTML estático pero quieren mejorar
la experiencia de usuario.
