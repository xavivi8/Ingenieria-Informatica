## Descripción breve

Este trabajo tiene como objetivo explicar el uso de Petite-vue, una herramienta ligera basada en Vue.js, para la 
creación de interfaces HTML interactivas de forma sencilla y eficiente.
A lo largo de la presentación, se introduce el contexto explicando brevemente qué es Vue.js, se comparan ambas 
tecnologías (Vue y Petite-vue), y se analiza su sintaxis básica con ejemplos prácticos.

También se presentan sus principales ventajas y desventajas, para comprender en qué escenarios es más útil usar Petite-vue.
El propósito final es mostrar cómo se puede añadir interactividad a páginas web estáticas sin necesidad de frameworks 
complejos ni configuración avanzada, destacando así su utilidad en proyectos pequeños o integraciones rápidas.
